\# AI Air Whiteboard



AI-powered virtual whiteboard using computer vision and hand gestures.



\## Features



\- Hand gesture drawing

\- Open palm eraser

\- Closed fist clear board

\- OCR text recognition

\- Equation solving using SymPy

\- Real-time hand tracking



\## Tech Stack



\- Python

\- OpenCV

\- MediaPipe

\- NumPy

\- Pytesseract

\- SymPy



\## Installation



```bash

pip install -r requirements.txt

```



\## Run



```bash

python main.py

```



\## Controls



| Gesture | Action |

|---|---|

| ☝️ | Draw |

| ✌️ | Space |

| ✋ | Eraser |

| ✊ | Clear Board |

| r | OCR + Solve |

| q | Quit |
